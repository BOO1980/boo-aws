Amazon S3 - Overview

  • Webpages that run special scripts on the web server are called server side scripts
  • Webpages that run scripts on the user's browser are called client side scripts
  • Webpages that don't use scripts are called static websites
  • Webpages that are static can be moved to Amazon S3 to use its web hosting feature
  • Using Amazon S3 website hosting allows you to control who has access to your webpage
  • With Amazon S3 you can store any kind and amount of data and access it from anywhere
  • Amazon S3 is a fully managed servicve, which means AWS handles all the server work for you
  • Amazon S3 automatically copies your data across multiple data centers to keep it safe and available
  • Amazon S3 can handle thousands of visitors at the same time wihout any extra work
  • Amazon S3 provides storage and retrieval of any amount of data from anywhere on the web.
  • Amazon S3 is an object storage service
  • An Object consists of both data and attached metadata
  • The metadata is a set of name-value pairs that describe the object
  • Buckets are containers for objects stored in S3
  • An object is uniquely identified by a key within a bucket
  • For example: an image file is uploaded to a uniquely named s3 bucket, it becomes and object which contains image data and any added meta data, such as time created and location
  • Amazon S3 offers industry leading scalability, data availability, security, and performance
  • Custoomers of all sizes and industries can use it to store and protect any amount of data for a range of use cases such as websites, mobile applications, backup and restore, archieves, enterprise applications , IoT devices and big data analytics
  • Amazon S3 can easily meet fluctuating demands and handle large amounts of data without any performance degradation by automatically scaling your storage
  • Amazon S3 is designed for 99.999999999% durability and 99.99% availability of objects over a given year
  • Because Amazon S3 automatically creates and stores copies of all s3 objects across multiple locations, it ensures data durability and availability even in the event of hardware failures, threats, errors or other disruptions.
  • Amazon S3 also offers leading security, compliances and audit capabilities. it secures your data from unauthorised access, with encryption features and access management tools
  • S3 allows you to block public access to all of your objects at the bucket of the account level with S3 block public access
  • You should enable block public access for all accounts and buckets that you do not want publicly accessible
  • S3 maintains compliance programs such as PCI-DSS, HIPAA/HITECH, FedRAMP, EU Data Protection Directive and FISMA
  • To help you meet regulatory requirements, S3 also supports numerous auditing capabilities to monitor access requests to your S3 resources
  • Amazon S3 is widely supported and intergratred with many applications and services
  • You can choose to work with a partner from the AWS partner network or APN which is the largest community and consulting services providers
  • Migration partnets can help you transfer data to Amazon S3
  • Storage partners offer integrated solutions for primary storage, backup and restore, archiving, disaster recovery and data management
  • You can also purchase and AWS integrated solutions from the AWS Marketplace which lists over 250 storage specific offerings

Amazon S3 - More Features

  • Amazon S3 provides a wide range of storage classes to help you optimize cost and performance for your data
  • Amazon S3 storage classes include: S3 Standard, S3 Intelligent-Tiering, S3 Standard-IA, S3 One Zone-IA, S3 Glacier and S3 Glacier Deep Archive
  • Each S3 storage class provides supports a specific data access level.
  • S3 standard is for general purpose storage of frequently accessed data.
  • It delivers low latency and high throughput, and can access data in milliseconds.
  • S3 Intelligent-Tiering is designed for data with unknown or changing access patterns.
  • It automatically moves your data between a frequent access and infrequent access tier based on changing access patterns - without performance impact or operational overheads
  • S3 standard IA and S3 one zone IA are for long lived but less frequently accessed data
  • Since S3 one zone infrequent access only stores data in one availability zone, it is less resilient to availability zone failures compared to other S3 storage classes
  • S3 Glacier storage classes are for long term archive and digital preservation
  • S3 Intelligent Tiering, S3 Standard IA and S3 One Zone IA also have the same low latency and high throughput performance as standard
  • S3 glacier instant retrieval storage class delivers the lowest cost storage with milliseconds retrieval. It is designed for achieve data that needs immediate acces
  • For achieve data that does not require immediate access, choose s3 Glacier flexible retrieval, with retrieval in minutes or free bulk retrievals in 5 to 12 hours
  • To save even more on long lived archieve storage, choosee S3 Glacier Deep Arcieve the lowest cost storage, with data retrievel from 12 to 48 hours
  • Amazon S3 also providesa easy to use management tools for granular data control
  • You can use S3 storage class analysis to discover data that should move to a lower cost storage class based on access patterns
  • Then you can use the analysis infomation to configure an S3 lifecycle police that makes the data transfer
  • S3 lifecycle policy defines when objects transition to another storage class and when the objects expire
  • It helps to manage your objects so that they are stored cost effectively throughout their life cycle
  • You can use S3 cross-region replication to replicate data into other AWS regions. You can also replicate data within the same AWS region
  • S3 Object lock is when objects are locked for the duration the retention period that you define and are protected from deletion
  • You can enforce, write-one, read-manyu policies with S3 object lock
  • S3 can do inventory report lists of your stored objects, their metadata and encryption status
  • You can also use S3 batch operations to change object properties and perform storage management tasks for billions of objects
  • With S4 batch operations and a single S3 API request, or a few clicks in the Amazon S3 management console, you can perform bath operations such as, copy object between buckets, replace object tag sets, modify access controls and restore archived objects from Amazon S3 Glacier
  • Since Amazon S3 works with AWS Lambda you can log activities, define alerts and automate workflows withou managing additional infrastructure
  • With query in-place services, you can run big data analytics directly across your S3 object and other data sets in AWS, this means you can run big data analytics directly on your data stored in Amazon S3 that allows you to query data without needing to copy and load it into a seperate analytics platform or data warehouse
  • Amazon S3 is also compatible with AWS analytic services, Amazon Athena and Amazon redshift spectrum
  • You can use Amazon Athena to query S3 data with standard SQL expressions
  • Amazon Redshift spectrum also runs SQL queries directly against data at rest in Amazon S3, and is more appropriate for complex queries and large data set up to exabytes
  • You can also use S3 select to retrieve subsets of object data instead of the entire object, which can be up to five terabytes in size.
  • Redshift is designed to increase query performance up to 400 percents and reduce querying costs as much as 80%
  • Another feature is versioning which means keeping multiple variants of an object in the same bucket
  • Buckets can be in one of three states: un-versioned, which is the default, versioning enabled, or versioning suspended
  • When versioning is suspended it will suspend the creation of version ID for new objects but preserve all the existing object versions
  • Once you enable versioning the combinaton of a bucket key and version ID uniquely identifies each other
  • After the bucket is versioned enabled, it can never return to an unversioned state
  • You can use versioning to preserve, retrieve and restore every version of every object stored in your S3 bucket
  • Versioning enabled buckets enable you to recover objects from accidental deletion or overwrite
  • If you delete an object it is not permanently deleted, Amazon S3 inserts a delete marker
  • If you overwrite an object, it results in a new object version as long as the object has not been deleted
